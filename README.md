# Purls-of-Wisdom
A shop management system created for a local crafts business using C#/.NET as part of my A-Level Computer Science NEA.

Key features:

Automated real-time notifications engine for event overbooking, outstanding payments, stock tracking, and order status tracking.
FIFO event waitlist system built on a custom linked-list-based queue class for fair capacity management.
Multi-page PDF invoice generator developed for use with an integrated receipt printer.
Customer membership system implemented across all online and in-store orders.
